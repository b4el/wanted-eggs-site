# Wanted Eggs — site

Site público do app [Wanted Eggs](https://b4el.github.io/wanted-eggs-site/): página inicial, **Termos de Uso**, **Política de Privacidade** e **Excluir conta** (link exigido pelo Google Play).

- Publicado pelo GitHub Pages a partir da branch `main` (pasta raiz).
- Os HTML são gerados por `build.py`. Para mudar um texto: edite o `build.py` e rode `python3 build.py`.
- Ao mudar Termos ou Privacidade, atualize `ATUALIZADO` no topo do `build.py` e avise no app.
